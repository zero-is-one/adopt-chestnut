# Chestnut's Cozy Corner

A static adoption spotlight for Chestnut. The page is ready to publish from the root of the `zero-is-one/adopt-chestnut` repository with GitHub Pages.

## Publish with GitHub Pages

1. Add the contents of this folder (`index.html`, `style.css`, and `assets/`) to the repository root.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select the default branch and the **/(root)** folder, then save.
4. GitHub will show the published URL in the Pages settings after its first deployment.

The page uses only static files. GIFs are optimized 4-second loops converted from the supplied videos. Google Fonts are an optional external font source; the site falls back to system fonts if unavailable.
